# Launch artifacts

Create these files as the workflow progresses. Keep them merchant-readable and update rather than overwrite prior decisions.

## `research-brief.md`

Sources, evidence, opportunity hypotheses, risks, merchant-approved direction, and Firecrawl-informed Shopify Collective discovery search queries with exact `searchTerm`s.

## `brand-brief.md`

Audience, positioning, voice, visual direction, product constraints, budget, marketing channels, consent requirements, and merchant decisions.

## `catalog-plan.md`

Draft product/collection plan, pricing hypotheses, imagery requirements, policies, supplier/fulfillment validation, Shopify Collective search terms, instant-import sourcing status, verified merchant-confirmed Collective products, and the approval state for catalog changes.

## `campaign-plan.md`

Creative brief, product and brand imagery plan, accessibility alt text rules, approved/generated asset links, asset status manifest, human review checklist, paid generation approval state, and marketing approval state.

## `launch-checklist.md`

Store setup, store domain/handle, Collective app install status, Shopify Admin Collective discovery links, sourced Collective products, theme preview, domain/DNS, policies, QA, owners, blockers, and explicit launch approvals.
